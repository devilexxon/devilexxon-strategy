Privacy Policy

Last updated: 26 November 2026

CoC Animation Shorts is a private tool used only by the owner of the strategy gaming YouTube channel "DevilExxon: Strategy" to upload and schedule the channel's own Clash of Critters animation Shorts.

What the app accesses

  • With the owner's permission (Google sign-in), the app uses the YouTube Data API to upload videos to the owner's channel, set their titles, descriptions and publish times, and read public video search results and the channel's name.
  • It does not access anyone else's account, and it is not offered to other users.

What is stored

The Google sign-in token is stored only on the owner's own computer, so uploads can run on schedule. No data is sold, shared with third parties or used for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at https://myaccount.google.com/permissions.
